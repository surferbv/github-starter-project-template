CS 138 / CS 139 GitHub glossary and mini-lesson assignment

An open pedagogy assignment for Python courses in which students create reusable glossary entries, worked examples, and inclusive learning notes.

Overview

In this assignment, students help build a shared open Python learning resource for current and future students. Each student selects one Python concept, programming practice, or dataset-related skill and creates a short glossary entry, worked example, and mini-lesson.

Purpose

The assignment connects antiracist teaching with open pedagogy by asking students to explain technical ideas in accessible language, choose examples with attention to representation and context, and contribute to a reusable course resource.

Students are treated as contributors to course knowledge, not only as consumers of instructor-created material.

Student Contribution

  • A clear definition of the selected concept
  • A short explanation of why the concept matters
  • A working Python code example
  • A plain-language walkthrough of the code
  • An inclusive learning note
  • Credits for any dataset, image, text, or code adapted

Suggested Topics

  • Variables, data types, and expressions
  • Conditional logic
  • Loops and iteration
  • Lists, dictionaries, tuples, or sets
  • Functions
  • File input and output
  • Data cleaning or visualization
  • Testing or debugging strategies

Required Structure

# Concept name

## Definition
Explain the concept in 2-4 sentences.

## Why it matters
Describe where this concept appears in Python programming or data work.

## Example
Include a working Python code block.

## Walkthrough
Explain the example step by step.

## Inclusive learning note
Describe one choice that makes the explanation, example, or dataset more
inclusive and accessible.

## Credits
List any sources, datasets, or adapted materials.

Peer Review Questions

  • Is the explanation technically accurate?
  • Would the explanation make sense to a student new to the topic?
  • Does the code run successfully?
  • Does the example avoid unnecessary assumptions about students' backgrounds?
  • Does the inclusive learning note identify a real design choice?
  • What is one specific revision that would improve the entry?

Assessment Criteria

  • Technical accuracy
  • Clarity
  • Inclusive design
  • Open resource quality
  • Attribution
  • Revision
